# Joke's on You

**Joke's on You** is a Vanilla+ Balatro mod that adds new content to the game, introducing weird new strategies or enhancing ones that already exist.

The mod is in an alpha state, so any and all bug reports or suggestions are more than welcome. As of right now, it contains:

- 30 new Jokers
- More content on the way...

## Installation

1. Make sure that [Steamodded](https://github.com/Steamodded/smods/wiki) **v1.0.0+** _(or newer)_ is installed.
2. Download the [latest release](https://github.com/tepschmep/jokes-on-you/releases)'s source code `.zip`.
3. Unzip the mod on Balatro's mod directory (ie. `%appdata%/Balatro/Mods`). _Make sure the unzipped folder is not nested!_

> Note: instead of following steps 2 and 3, you can clone this repository's `main` branch and run `git pull` to get updates.

> If you're okay with bugs and want to check out new features before updates, you can clone the `dev` branch.

## Feedback & Contribution

Thank you for playing the mod! We're looking for more playtesting and feedback as we continue to develop and polish rough edges. PRs are welcome!

If you happen to find a bug, please use our [Issues](https://github.com/tepschmep/jokes-on-you/issues) board and **make sure to describe the problem clearly**. Leave instructions on how to reproduce the bug in your report.
